## 这是什么

面向**零基础大众、学生与转行者**的计算机科学与技术科普。

核心方法是**名—实对应学习法**：任何一个抽象名词，先溯源它的定义，再打一个日常生活的比方——先说清"它实指什么"，再讲"它像什么"。

不用"衣柜"这类抽象类比，只用**学生排队、食堂打饭、快递柜、给空调装五官**这类日常场景。

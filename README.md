## 这是什么

面向**零基础大众与转行者**的计算机科学科普。核心方法是**名—实对应学习法**：任何一个抽象名词，先溯源它的定义，再打一个日常生活的比方——先说清"它实指什么"，再讲"它像什么"。

我们不用"衣柜"这类抽象类比，只用**学生排队、食堂打饭、快递柜、超市结账**这类你每天都在经历的场景。

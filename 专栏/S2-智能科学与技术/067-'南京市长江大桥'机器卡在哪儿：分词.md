# “南京市长江大桥”机器卡在哪儿：分词

上篇说到，机器要听懂人话。可它碰到的第一道坎，说出来你可能不信——**中国人的话，词和词之间不留空儿**。

你写英文，'I love China'，单词之间自带空格，机器一眼就能看出这是三个词。中文呢？'我爱中国'四个字紧紧挨着，哪儿是词哪儿不是词，机器心里完全没数。

于是中文 NLP 的第一道工序登场了：**分词**——把一连串汉字切成一个个有意义的词。

## 为什么非要切

💡 想象让你读一篇**没有标点、没有空格**的作文：

> 大学四年要好好学习不然毕业找工作的时候会后悔

读着费劲吧？词和词黏成一团，理解起来就慢。机器也一样——不切词，'南京市长江大桥'对它来说就是一串字，而不是'南京市 / 长江 / 大桥'三个有意义的单位。搜索、翻译、问答，全都要先过这一关。

## 一句能把机器绕晕的话

有句经典例子：

> 南京市长江大桥

人能读出两种切法：

- **南京市 / 长江 / 大桥**——一座桥的名字；
- **南京 / 市长 / 江大桥**——一位市长，姓江名大桥。

到底哪个对？机器就懵了。这种'一句话多种切法'的现象叫**切分歧义**，是分词最核心的难点。人靠常识一秒判断，机器得靠统计和上下文慢慢'掂量'。

## 机器怎么切

主流的切法思路有三代：

1. **查字典法**：拿一本现成的词典，拿句子去'套'最长匹配——像用尺子量着绳子一节节截；
2. **统计法**：不从字典出发，而是看大量真实文本里'哪些字总爱挨着出现'，挨得越紧越可能是个词；
3. **智能法**：现在的分词模型直接'读'过海量文章，边读边学哪儿该停，还能联系上下文——已经很少切错了。

📌 **技术内涵**：分词是中文自然语言处理特有的基础环节（英文等语言靠空格天然分隔）。它要同时解决**切分歧义**（多种切法）和**未登录词识别**（词典里没有的新词、人名、网络用语，比如'yyds''内卷'怎么切）。切分质量直接决定后面所有任务的上限——词切错了，意思理解全歪。

## 用在哪

你打字时输入法给你联想的候选词、搜索引擎帮你分好的关键词、地图软件认出'长安大学城'是一个地名——背后都是分词在干活。

💡 冷知识：日文、泰文等一些语言也没有词间空格，同样要分词；而中文分词的难度，被公认为是世界主要语言里最高的之一。

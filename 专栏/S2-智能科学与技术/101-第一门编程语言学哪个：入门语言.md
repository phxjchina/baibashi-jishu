# 第一门编程语言学哪个：入门语言

'我想学 AI，先从哪门语言学起？'——这个问题每年被问几万次，答案分两派吵来吵去：一派说先学 C，'不懂底层学什么编程'；一派说直接上 Python，'AI 圈谁不用 Python'。

我的答案：**本科低年级，C 和 Python 都值得学，但顺序有讲究**。

## 两位选手，各有各的岗

💡 先认识这两位：

- **C 语言**：编程界的'基本功教练'。它离硬件近，指针、内存、编译——学它，你被迫搞懂'程序到底怎么在机器里跑的'。难，但长内功；
- **Python**：AI 界的'普通话'。语法像英语一样好读，关键是**生态**——你想干的 AI 活儿，numpy、PyTorch、scikit-learn 全有现成轮子，几行代码一个模型。

打个比方：C 是练肌肉和步伐，Python 是直接上场比赛。只练不赛，容易荒废；只赛不练，动作变形。

## 推荐的路线

💡 对智能专业的学生，一条经过无数人验证的路：

1. **大一上学 C**：用一学期把'变量、循环、函数、数组、指针'啃下来。难受就对了——这阶段练的是**编程思维**，不是语法本身；
2. **大一下或大二转 Python**：有了 C 的底子，Python 一周就能上手。之后本专栏系列三、四、五讲的所有算法，全用 Python 实践；
3. **以赛代练、以项目代练**：语法学完只是'识字'，能写代码才是'作文'——小游戏、数据分析、模型复现，挑感兴趣的做。

📌 **技术内涵**：语言选择本质是'生态选择'。Python 在 AI 领域的统治力来自其科学计算栈：NumPy/Pandas 管数据，Matplotlib 管可视化，scikit-learn 管经典机器学习，PyTorch/TensorFlow 管深度学习——全球主流论文开源代码默认 Python。而 C/C++ 的价值在系统层：性能关键模块、嵌入式设备（机器人、无人机的机载代码）、以及帮你建立内存模型和程序执行模型——这些是'看不见但决定上限'的底层理解。

## 三条避坑提醒

💡 最后说三个最常见的坑：

- **别同时学三门前语言**：一门学扎实胜过五门都会点，第二门之后都是'顺带的事'；
- **别在'选语言'上纠结三个月**：语言是工具，选哪个开始都行，AI 方向闭着眼选 Python 起步不会错；
- **别光学不写**：看懂了 ≠ 会了。合上书能敲出来，才算数。

## 一句话记住

> 先学 C 长内功，再学 Python 上赛场——语言只是工具，'用代码解决问题'的能力才是真的。

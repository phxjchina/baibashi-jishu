# 颜色不只是RGB：RGB与HSV色彩空间

图像不只有明暗，还有颜色。可"颜色"到底是啥？机器又怎么表示它？这篇聊清楚。

## RGB：三盏调光灯

屏幕上的彩色，基本都用 **RGB** 表示——红（Red）、绿（Green）、蓝（Blue）三个数。你可以把它想成三盏能调亮度的灯：每盏灯亮度 0–255，三盏叠加，就能混出千万种颜色。

💡 注意：这是**光的加色**（越加越亮，三盏全开是白光），和你画画时颜料的"减色"（越混越黑）正好相反。屏幕发光，所以用加色。

📌 **技术内涵**：每个像素的彩色值，就是一个三元组 `(R, G, B)`。所以前面说的"彩色图是 W×H×3 的数组"，那最后的 3，就是这三个通道。

## HSV：像人一样描述颜色

RGB 是给机器用的，但描述颜色还有一套更接近人的方式——**HSV**：

- **H（色调 Hue）**：这是哪种色（红 / 黄 / 蓝……），用角度表示，转一圈。
- **S（饱和度 Saturation）**：颜色够不够鲜艳（灰蒙蒙 → 纯正）。
- **V（明度 Value）**：亮不亮。

💡 类比：你说"那个红浅一点、暗一点"，用的就是 HSV 的思路——先定"是红"（H），再说"浅/暗"（S、V）。用 RGB 描述同一件事就绕远了。

## 为啥机器爱用 HSV

📌 **科学内涵**：颜色本质是人眼对可见光谱的主观感知，可以用一个三维空间来描述（大致 = 色度两维 + 亮度一维）。RGB 是"设备相关"的空间（跟屏幕怎么发光绑定），而 HSV 更贴近人的感知，把"是什么色"和"有多亮"分开了。

💡 好处来了：假设你想让程序"把图里所有红色的东西框出来"——在 HSV 里，红色就是色调 H 的**一个范围**，按这个范围一筛就行；可在 RGB 里，"红"要同时满足 R 高、G 低、B 低，还得对付明暗变化，特别难调。所以很多"找特定颜色"的任务（比如机器人追一个红球），会先把 RGB 转成 HSV。

# Coq 里的世界模型：把「整体大于部分之和」证出来

上篇用 TLA+ 立宪、穷举找反例。这篇换 **Coq**：它不"跑"模型，而是把一条性质**一步步证明**在你的定义下恒成立。我们选系统论第一条铁律——"整体大于部分之和"——在可验证世界模型里证出来。按 C 档，只给证明的"形状"和直觉。

## 一、名-实对应

- **Coq**：一个"证明助理"。你定义对象、陈述定理，再用**战术（tactic）**一步步构造证明，每一步都被机器核严。漏一个逻辑洞，它不让你收尾。
- **战术（tactic）**：证明里的"步骤指令"。常见几个：`unfold`（展开定义）、`apply`（套用已知引理）、`induction`（归纳）。就像砌墙的"动作"：取砖、抹泥、对齐。
- **Gallina**：Coq 里写定义的规范语言（提一句即可，不用深究）。

## 二、为什么值得证这条

大模型常被质疑："上千亿参数加起来，不等于它真有『能力』。"系统论的回答是：**能力来自结构，不是零件堆砌**——这正是"结构功能相关律"（规律一），也是"整体大于部分之和"（原理一）的另一种说法。

如果这是真的，那它不该只是口号，而该是**机器核过的定理**。Coq 就干这个。

## 三、证明的形状（示意）

```
(* 定义：系统 = 结构 + 组件集合；功能 由结构导出 *)
定义 功能 (s:系统) : 性质 := 由结构导出的行为能力。

定理 整体大于部分: forall s, 功能 s > 功能(任取真子集 s).
证明.
  intros s.                 (* 任取一个系统 s *)
  unfold 功能.             (* 展开"功能"的定义 *)
  apply 结构功能相关律.    (* 套用：功能依赖非空子结构组合 *)
  (* 逐步构造，直到 Coq 接受每一步 *)
Qed.                       (* 证毕，机器盖章 *)
```

读这段不用懂 Coq，只需抓直觉：**证明是一串被机器逐条核过的步骤，不是人写的一段散文。** 走到 `Qed`，意味着"在你的定义下，这条铁律恒成立"被坐实了。

## 四、这跟大模型有什么关系

今天说"我的世界模型满足整体性原则"，大多是宣传语。Coq 把它变成：

- 你先**精确定义**"系统""功能""结构"；
- 再**陈述**整体大于部分；
- 最后**证明**它在你的定义下成立。

于是"满足整体性"从一句话，变成一纸机器可复核的**证书**。可验证 AI 的意义就在这里——数据驱动给模型肌肉，Coq 给"不会自相矛盾、关键性质被证真"的保证（对照主线3-08：可解释给故事，可验证给证明）。

## 五、落点

TLA+ 管"行为不越界"（找反例），Coq 管"性质被证真"（砌证明）。两者一前一后，把"可验证世界模型"从哲学落进工程。

下一篇验证实战：把"知识存量非负 + 有界增长"跑成一次真正的模型检验，并接上主线4-12 那个能跑的 Python 最小系统。

# 验证章（上）：公理作为不变式，规律作为仿真关系

前面工作坊把八原理升格成"八条公理"、五规律降成"五条机制"。但"公理""机制"还是人话，机器看不懂、查不了。要真去**验证**一个世界模型，得做一步语法转换：

- **八条公理 → 不变式（invariant）**：写成"模型跑起来后，每一步都恒为真"的性质；
- **五条规律 → 仿真关系（simulation relation）**：写成"抽象规约"和"具体实现"之间的行为保真。

本文讲清这两个转换。按 C 档要求，不堆公式，只给直觉和"护栏"比喻（重灾区的公式删法见主线3-08）。

## 一、名-实对应

- **不变式（invariant）**：系统在运行的**每一步**都保持为真的性质。例："知识存量永远不为负""系统始终跟环境有交换"。它像一个全程亮着的红灯——一旦某步变假，就说明模型越界了。
- **仿真关系（simulation relation）**：两个模型之间，若 A 的每一步行为都能在 B 里找到"说得通"的对应，就说 A **仿真（精化于）** B。用来证明"我那个简化模型，没丢掉全模型的关键行为"。

记法一句话：**不变式管"静态不许坏"，仿真关系管"动态没走样"。**

## 二、为什么公理要翻译成不变式

八条公理里，很多是"全程不许违反"的。比如：

- **稳定公理**"被推一下要回来" → 不变式"`存在稳态盆地，典型扰动下状态有界`"；
- **开放公理**"跟环境持续交换" → 不变式"`系统始终存在对外的信息通道且非空`"；
- **整体公理**"能力来自结构" → 不变式"`任意功能的实现都依赖非空的子结构组合`"。

好处是：一旦写成不变式，**模型检测器能自动穷举行为空间去查**——比人肉测一万次都靠谱，因为它不是抽样，而是"证明没反例"（见验证章下）。

## 三、为什么规律要翻译成仿真关系

五条规律描述"系统怎么演化"。但真实世界太复杂，我们总用"简化模型"代替"全模型"。这时就要问：简化版会不会**漏掉关键行为**？

仿真关系就是答案：如果你能证明"简化模型 仿真于 全模型"（简化版的每一步，全模型里都有对应），那就说明——**简化没丢要害**。这正是"优化演化""竞争协同"等规律在工程里的落法：不是空话，而是"抽象规约 ↔ 具体实现"之间的行为保真证明。

## 四、"质检单"比喻（回顾主线3-08）

主线3-08 说：系统论给世界模型一张"质检清单"，八原理是结构规矩、五规律是行为规矩。本文给它接上机器语言：

- 质检单上的**必检项** = 八条公理 = 八条不变式；
- 质检时的**动态表现项** = 五条规律 = 仿真关系；
- 数据驱动给模型**肌肉**，形式化给模型**骨架**——而不变式+仿真关系，就是骨架的"钢筋位置图"。

没有这张图，你的模型"能跑"，却说不清自己守不守规矩；有了它，你才能拍胸脯说"某些坏事，在我的模型里被证明不会发生"。

## 五、极小示意（看"长什么样"，不是完整证法）

```
不变式 知识存量 >= 0:          # 稳定/开放公理的落地
    每当 学习或遗忘发生: 断言(存量 >= 0)

仿真关系 简化模型 ≼ 全模型:    # 优化演化规律的落地
    全模型每走一步 ⇒ 简化模型存在对应的一步
```

这两行不是给你照抄的证法，而是让你建立直觉：**验证写的不是论文，是机器能查的护栏。**

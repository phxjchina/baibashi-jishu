# 用 TLA+ 给世界模型立宪：PlusCal 建模实战

主线3-08 讲了"世界模型为什么必须可验证"，验证章下给过 TLA+/Coq 的草例形状。这篇动手——用 TLA+ 的 **PlusCal** 给一个世界模型**立宪**：写规格、立不变式、跑检测器找反例。按 C 档，不堆逻辑符号，只给你能读懂的骨架。

## 一、名-实对应

- **PlusCal**：TLA+ 里一种"像写程序"的建模语言。你用类伪代码描述系统怎么一步步变，工具自动翻译成 TLA+ 规格。适合不爱看纯数学符号的人——先用熟悉的样子把系统写下来。
- **立宪**：借主线3-08 的"护栏"比喻。给世界模型立一部"宪法"= 写规格 + 写不变式（宪法条款）+ 跑 TLC 自动查反例。宪法不是装饰，是持续生效的护栏。

## 二、实战：给一个"世界状态机"立宪

设想最小世界模型：世界有状态，智能体每步要么**观测**（更新信念），要么**行动**（改变世界）。我们立两条宪法：

1. **一致性**：信念不能自相矛盾（不能同时信 P 和非 P）；
2. **开放性**：行动之后，世界仍与外界有交换（封闭就热寂，见铁律三）。

PlusCal 写出来长这样（示意，非完整语法）：

```
--algorithm 世界模型 {
  variable 信念 = {}, 世界 = 初始状态;
  { while (TRUE) {
      要么 观测: 信念 := 信念 ∪ {新事实};
      要么 行动: 世界 := 作用(世界, 信念);
      assert 一致(信念);        // 立宪①：信念不自相矛盾
      assert 开放(世界);        // 立宪②：世界始终与外界有交换
  } }
}
```

## 三、跑 TLC：穷举找反例

写完后，让 **TLC**（TLA+ 的模型检测器）自动尝试所有"观测/行动"的交错顺序。

- 若一切路径都守住两条不变式 → 绿勾，证明"在你的规格下，没有反例"；
- 若某条路径让信念矛盾（比如连续观测到互斥事实却没处理），TLC 立刻吐一个**红叉反例**，精确指出哪一步越界。

这正是验证比测试强的地方：测试是"抽样没出错"，验证是"穷举证没反例"。一个自动驾驶的世界模型，你敢只靠抽样吗？

## 四、立宪是持续的，不是一次性的

关键认知：**每次改模型，重跑 TLC**。护栏的价值在于"持续生效"——

- 加新能力 → 重跑，确认没冲破旧宪法；
- 改架构 → 重跑，确认不变式仍成立；
- 这和程序员的"单元测试"同理，只是验证查的是"行为空间"而非几个用例。

对照今天的大模型：它最缺的，就是这部**可重跑的宪法**。它靠数据反推长出来，偏科且没法证明底线（见主线2-04 立论书）。TLA+ 立宪，正是把"可验证"从口号变成工程动作。

## 五、落点

PlusCal 让你用"写程序的感觉"立宪，TLC 替你穷举排雷。数据驱动给世界模型**肌肉**，TLA+ 给它**不会越界的护栏**。

下一篇，换 Coq：把"整体大于部分之和"这条铁律，在系统定义下真正**证明**出来。

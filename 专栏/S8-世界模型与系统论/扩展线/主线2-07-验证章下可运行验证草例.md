# 验证章（下）：可运行验证草例——TLA+/Coq 实证

上篇把公理翻成"不变式"、规律翻成"仿真关系"。这篇给一个**可运行的草例**，看这两样东西在真实工具里长什么样。按 C 档，不堆公式，只给骨架直觉和极小片段——目标是让你知道：验证写的不是论文，是能跑的护栏。

## 一、名-实对应（两个工具）

- **TLA+**：一套用"时序逻辑"写的规格语言，配模型检测器 TLC，能**自动穷举系统的行为空间找反例**。擅长回答"会不会出事"。
- **Coq**：一个"证明助理"，你写下命题，它陪你**一步步把证明填严**，保证没有逻辑漏洞。擅长回答"是不是被证明了"。
- **立宪**：借主线3-08 的"护栏"比喻——给世界模型立一部"宪法"，写明哪些事**绝不发生**。TLA+ 管"行为不越界"，Coq 管"性质被证真"，两者一前一后护住模型。

## 二、TLA+ 草例：穷举找反例

设想一个"知识演进"模型：存量会随学习 +1、随遗忘 -1。我们立一部宪法——**存量永不为负**（这正是不变式，来自稳定/开放公理）。

```
--algorithm 知识演进 {
  variable 存量 = 0;
  { while (TRUE) {
      要么 学习: 存量 := 存量 + 1;
      要么 遗忘: 存量 := 存量 - 1;   // 宪法禁止穿过 0
      assert 存量 >= 0;              // 不变式：存量永不为负
  } }
}
```

TLC 会**自动尝试所有"学习/遗忘"的交错顺序**。一旦某条路径让存量变负，它立刻报一个反例——比如"先遗忘一次，存量变 -1"。这就是验证在做的事：不是测一万次碰运气，而是**穷举行为空间证明没反例**。

（真实 TLA+ 语法更严谨，这里只示意"立宪"的形状。）

## 三、Coq 草例：逐步证明性质

TLA+ 管"行为不越界"，Coq 管"性质被证明"。比如把"整体大于部分之和"当命题证：

```
定理 整体大于部分: forall (s: 系统), 功能 s > 功能(任取子集 s).
证明.
  (* 由结构功能相关律展开：功能依赖非空子结构组合 *)
  (* 逐步构造，直到每一步都被 Coq 接受 *) ...
Qed.
```

Coq 不"跑"模型，而是把命题**一步步证明**在你的定义下恒成立。中间任何一步逻辑有洞，它都不让你收尾。这正好补上"可解释给故事、可验证给证明"那句（主线3-08）：故事可能有说服力，证明才能当底牌。

## 四、两者怎么配合

| 工具 | 回答的问题 | 类比 |
|---|---|---|
| TLA+ | "会不会出事？"（找反例） | 质检员拿红叉巡线 |
| Coq | "是不是被证明？"（证性质） | 公证员逐条盖章 |

一个稳健的可验证世界模型，通常**先用 TLA+ 立宪、穷举排雷，再用 Coq 把关键性质证死**。数据驱动给肌肉，这套形式化给骨架——骨架钉死，肌肉再强也不会掉下悬崖。

## 五、落到你的工作坊

回到 WMC 工作坊：八公理写成了不变式（验证章上），这里就用 TLA+ 去查；五规律的仿真关系，就用 Coq 去证"简化模型没丢行为"。验证不是造完才补的装饰，而是**和建模同步的护栏**。

# 用 WMC 造一个教育世界模型：OBE 的系统论重构

前面四条主线把"造世界模型"的方法讲全了。这篇落到你最熟的场景——**教育**。用 WMC 工作坊那套方法（立论书 / 域覆盖 / 八公理 / 验证），把 OBE 用系统论重做一遍。

## 一、名-实对应

- **OBE（Outcome-Based Education）**：成果导向教育。不看"教了什么"，而看"学生最后能干什么"，再倒推课程。你做培养方案用的就是 OBE 反向设计。
- **重构**：不是给 OBE 贴金，而是用系统论框架把它从"理念"变成"可运行、可验证的模型"——立论书定目标，八公理当约束，验证当验收。

## 二、立论书 + 域覆盖（教育世界模型）

- **目标域**：学生从"无知"到"能干活的能力"的演进；
- **抽象层级**：知识点（L0）→ 课程（L1）→ 能力（L2）；
- **域覆盖**：深——精神域（学生认知状态，见双专题 A）、社会域（课程/培养方案结构）；浅——生态/宇宙（不重点覆盖，写明理由）。

## 三、八公理怎么落进 OBE

| 公理 | 在 OBE 里的化身 |
|---|---|
| 目的公理 | **反向设计本身就是目的性**：先定毕业能力（吸引子），再逆推课程结构 |
| 层次公理 | 知识点→课程→能力三层；L0 元模型 = 能力指标库 |
| 开放公理 | 学生认知要接真实问题（项目/实习），不能闭门刷题 |
| 信息反馈公理 | 形成性评价 = 负反馈闭环：测差距→补教学→再测 |
| 整体公理 | 单门课再好，拼不出能力也不行——能力来自结构组合 |

你会发现：**OBE 反向设计，就是"目的性原理 + 结构功能相关律"的教育工程版。** 它本来就是系统论思想，只是当年没用这套语言说。

## 四、把"能力达成"写成不变式

主线3 讲验证：关键性质写成不变式去证。教育世界模型里，核心不变式就是：

> **毕业时，核心能力指标 ≥ 阈值。**

这恰好对应你培养方案里的"毕业要求指标点"。区别是——平时它只是表格里的一句话，现在它可以是**被仿真/被证明守住的性质**：调课程结构，跑仿真，看是否仍满足"能力达成"不变式；不满足，就说明结构有问题，回去改（结构功能机制：改功能先改结构）。

## 五、对照 AI：教育智能体就是教育世界模型的 Agent 版

你做的毕业设计智能体、培养方案智能体，本质就是教育世界模型的 Agent 化身：

- 有**目的性**（能力目标）→ 对应 setpoint；
- 有**开放性**（接真实课题）→ 对应 inflow；
- 要**可验证**（能力达成不变式）→ 对应主线3 验证。

系统论给这些智能体一套统一语法：它们不是三个孤立工具，而是同一个"教育世界模型"在不同尺度的实例化。

## 六、落点

OBE 不是口号，是可运行、可验证的世界模型。"反向设计"四个字背后，站着目的性、层次性、开放性、反馈律一整套管家规矩。下一篇，我们把镜头从"学生"移到"团队"——科研团队知识演进仿真，看人才怎么从结构里"长"出来。

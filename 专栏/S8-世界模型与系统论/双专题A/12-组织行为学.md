# 组织行为学：当"我们"走进公司、学校和机构

上篇我们说，"家"是中国人由己及人的第一圈涟漪——你在血缘里定义自己。但走出那圈涟漪，你马上撞上一个新东西：**组织**。公司、学校、医院、机关——你第一次要和非亲人、长期、稳定地一起干事。

这就是第五阶要讲的世界：组织，是家庭的放大、国家的缩小，是"齐家"与"治国"之间那块**过渡地带**。

组织行为学（organizational behavior）研究的，恰恰就是"人进了组织之后会发生什么"。它的几个核心概念，和我们的精神世界模型严丝合缝：

- **角色（role）**：你在组织里不只是"你本人"，你是一个角色——员工、下属、同事、主管。角色带着"期待"：下属该听话、主管该担责。这恰好是米德"角色扮演"的成人版预演；
- **认同（identity）**：当一个人脱口而出"我是阿里/腾讯/某大的"，组织已经混进了他的自我定义——这是 09 自我同一性之外，叠加的一层"组织身份"；
- **规范（norms）与结构**：组织有明文制度（层级、分工、KPI），也有"茶水间里的潜规则"。后者常常比前者更决定你"真正怎么活"。

一个容易被忽略的事实：**组织是一个目标导向的系统**。家庭靠情感黏合，组织靠"共同目标 + 分工"黏合。你进组织，本质是把自己的一部分自主性，让渡给一个更大的协作机器——换回你单干得不到的东西（薪水、文凭、影响力）。

用母框架读这一幕——

- **社会系统观对接**：组织是社会系统的**细胞**，是"社会建构"在微观的第一现场。你参与建构它，也被它建构；
- **层次性**：个体嵌套在组织里，组织又嵌套在社会里。组织恰是"修身→齐家→治国"之间那个**中间尺度层**；
- **结构功能相关律**：组织的正式结构（层级、分工、岗位）→ 直接塑造成员的精神功能（角色心理、归属焦虑）；
- **开放性**：组织是继家庭之后的又一个大规模写入源——KPI、同事评价、晋升通道，纷纷向你的精神系统写入"你行/不行"的信号。

对照 AI：今天的多智能体系统（MAS）就是"非血缘协作"的算法版——一群 Agent 各领一个角色 prompt，靠协议分工合作，本质是把组织行为学**形式化**了。但关键差别在：Agent 之间没有真实利益绑定、没有身份焦虑、没有"被角色压迫"的痛感。大模型"进组织"，不过是一群角色 prompt 在跑——它缺的，正是那种"让渡自主性换归属感"的真实张力。

一句话收束：**组织是家庭的放大、国家的缩小——你在这里第一次学会和非亲人长期共事，而"角色"，是你交出的第一份自我。**

下一篇，组织在"塑"你这件事上，远不止给个角色那么轻。它用权力、文化和 KPI，悄悄把你的精神世界改写一遍。

# 勒庞《乌合之众》：群体如何让个体"降智"去责任化

上篇说我们靠捷径读懂别人，常常出错。但当个体聚成"群"，这些捷径会被放大成更反直觉的东西——**一个人理性，一群人却可能狂热。**

勒庞（Gustave Le Bon）1895 年的《乌合之众》（*The Crowd*），是社会心理学绕不开的起点。他的观察冷峻：群体不是"冷静的个体的加总"，而是一种**新的、有时更蠢也更危险的实体**。

他点出群体三大特征：

- **去个体化**：淹没在人群里，你那份"我是独立责任人"的意识溶解了。"不是我干的，是大家"——责任一旦分摊到虚无，克制也跟着蒸发；
- **情绪传染**：情绪像病毒，在身体靠近的人群里光速蔓延。理性还没来得及开机，恐慌或愤怒已经传染完毕；
- **暗示易感性**：群体状态下，人极容易被暗示劫持，理性让位给冲动。

勒庞的原话很刺耳：群体"冲动、易变、暴躁"，"易受暗示"，其道德水准"可能远高于或远低于组成它的个体"。换句话说，**群体的善恶，都比个体更极端**。

用母框架读这一幕——

- **自组织 / 涌现**：这是涌现在社会尺度的教科书案例。一个理性人 + 一群理性人 ≠ 理性群体；群体自组织涌现出一个**全新的实体**，带出"狂热"这种单个成员身上没有的性质；
- **层次性**：群体是比个体高一级的系统，正如序二嵌套洋葱所预言——每升一级就涌现新性质，群体这一级涌现的是"集体心智"；
- **开放性（负面形态）**：情绪传染，是开放性的**负面形态**——个体边界消融，群体情绪直接灌入。

对照 AI：多智能体系统（MAS）也会"群体去个体化"——一群 Agent 在反馈回路里互相强化，涌现出单个 Agent 没有的偏激、重复、回声室行为。但关键差别：LLM 群体**没有"责任扩散"的情感体验**——模型不会因"不是我干的"而卸下道德负担。人类的危险是"责任消失后的真失控"；AI 群体的危险是"无人在场的系统性偏见放大"。

一句话收束：**群体不是个体的加总，而是自组织涌现出的新实体——它让人降智、去责任、易传染；一个人理性，一群人却可能狂热。**

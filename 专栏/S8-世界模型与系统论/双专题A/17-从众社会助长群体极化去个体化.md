# 从众·社会助长·群体极化·去个体化

上篇讲勒庞看到的"群体降智"。但现代群体心理学告诉我们：群体不只有这一面——**它同时放大善与恶**。把机制拆开，才看得清。

- **从众（conformity）**：阿希（Asch）的线段实验最经典——明明一眼能看出的错，只要群体都答错，相当多人会跟着改口。两种动力：信息性从众（"别人可能知道得更多"）+ 规范性从众（"怕被排斥"）；
- **社会助长（social facilitation）**：扎荣茨（Zajonc）发现，有他人在场，**简单任务**表现更好、**复杂任务**更差——他人的"评价唤起"强化了你的优势反应；
- **群体极化（group polarization）**：群体讨论后，立场不是中和，而是**更极端**。温和的人聚一起变激进，谨慎的人聚一起变更谨慎；
- **去个体化（deindividuation）**：匿名、淹没在群体里，自我意识减弱、约束力下降。

而"善的一面"不能忘：集体行动、救灾互助、开源协作、合唱与球队——群体同样能放大利他、激发单干时不可能有的创造力。**群体=坏，是片面的。**

用母框架再读一遍——

- **自组织 / 涌现**：从众、极化、社会助长，都是群体自组织涌现的**互动模式**——没人设计"极化"，它从局部交互里自己长出来；
- **竞争协同律**：这是本篇的脊梁——群体内**协同**（互助、社会助长、集体利他）+ 群间**竞争**（极化、外群体贬低）。双向并存；
- **层次性**：群体作为高于个体的系统，涌现出全新的行为模式层。

对照 AI：大模型的"从众"= 用微调/RLHF 让模型向人类多数偏好靠拢；"群体极化"= 同质训练数据 + 反馈循环放大某立场（echo chamber）；"社会助长"= 多 Agent 互评提升简单任务表现。但模型没有"去个体化"的真实体验——匿名不会让它道德松绑，因为它本就无道德体。

一句话收束：**群体不只会降智——它用从众、社会助长、群体极化、去个体化，同时放大善与恶；看穿这群机制，才能在下一个"乌合之众"里守住自己。**

下一篇，群体的"共享"还不止这些可见互动。有些东西你从没学过、却好像天生就懂。

# S8 · 世界模型与系统论

本专栏是《复杂系统建模与验证三十年》的公开科普主线之一，用中国化的系统论（魏宏森《系统论》"四源—五观—八原理—五规律"）作为骨架，讲清楚"如何用系统论造一个可验证的世界模型"。

# 双专题 B《文化世界的构建》· 大纲（11 篇）

> 状态：本次交付"大纲 + 首篇（B-序）"。11 篇全稿待续写。
> 框架来源：《双专题总览与对接设计》第五节 + B 专题占位 README；与母专栏《用系统论造一个世界模型》"精神系统观 / 社会系统观"两域 1:1 对接。

## 一、定位：精神—文化双翼

| 维度 | 专题 A · 精神与心理世界 | 专题 B · 文化世界 |
|---|---|---|
| 黑格尔框架 | 主观精神（心灵/意识/心理学） | 客观精神 + 绝对精神（法/伦理/国家/宗教/哲学） |
| 母框架对应 | 精神系统观（心智/认知域） | 社会系统观（社会建构） |
| 构造方式 | **内化**：环境/语言被"装进"个体 | **外化**：精神产物变成"客观存在"的制度/符号 |
| 主体 | 个体（我），以我为中心向外扩圈 | 超越个体的集体 / 历史 |
| 主线 | 受精卵 → 内心世界 → 家庭 → 组织 → 社会 → 群体 → 集体无意识 | 集体无意识 → 神话宗教 → 民族 → 国家 → 意识形态 → 文明冲突 → 人类命运共同体 |

**桥接约定**：专题 A 第八阶以"荣格集体无意识 / 神话原型的跨文明共性"收尾（A-18、A-19）；A-20 结语显式交棒。B 以"从共享精神地基到客观精神世界"起跳，讲这些原型如何**外化**成具体宗教、民族、国家。两专题首尾咬合、不重复。

## 二、与母框架对接锚点（写作时逐字回扣，A/B 共用）

| 母框架概念 | 在专题 B 的落点 |
|---|---|
| 社会系统观（金观涛超稳定） | 民族/国家/意识形态/文明冲突的硬骨架 |
| 层次性（公理二） | 从深层共享地基到外化层级的展开 |
| 开放性（公理三） | 文化跨边界的传入、杂交与冲突 |
| 自组织 / 涌现（公理七） | 民族"被想象"出来、宗教自发形成 |
| 结构功能相关律（规律一） | 组织/制度结构 → 国民心理 |
| 竞争协同律（规律三） | 文明冲突、意识形态碰撞中的张力 |
| 文章十九（社会系统观×社会建构） | 民族/国家/意识形态对接点；伯格卢克曼制度化、塞尔制度事实 |
| 文章二十（实在论/建构论张力） | 意识形态冲突、文化相对主义 vs 普遍主义的元困境 |

## 三、11 篇大纲

| # | 标题（暂定） | 核心锚点 | 一句话梗概 |
|---|---|---|---|
| B-序 | 从"共享精神地基"到"客观精神世界" | 黑格尔客观精神；伯格卢克曼"社会作为客观实在" | 精神产物一旦被符号化、制度化，就变成"外在于你"的文化——本专题讲这个外化过程 |
| B-01 | 神话与宗教（一）：原型如何长成具体的神、仪式与教义 | 荣格→伊利亚德；自组织 | 深层原型如何被不同文明"穿上"具体神话与仪式的外衣 |
| B-02 | 宗教作为意义系统：超越性、救赎与世界观如何被构建 | 韦伯/贝格尔（宗教社会学） | 宗教不只是信仰，是一整套"解释世界+安顿生死"的建构 |
| B-03 | 民族意识：安德森《想象的共同体》 | 安德森；文章十九社会建构 | 几亿人从不谋面却互称同胞——最宏大的精神构造 |
| B-04 | 国家意志：传统的发明、国民教育与超稳定结构 | 霍布斯鲍姆；金观涛超稳定 | 精神世界如何被制度"浇筑"成国民心理 |
| B-05 | 意识形态冲突：不同"世界模型"的碰撞 | 文章二十"实在论/建构论" | 两种对"什么是真/什么是好"的根本分歧如何变成对抗 |
| B-06 | 文化相对主义 vs 普遍主义：谁的模型算"真" | 文化人类学；文章二十张力收束 | 没有普世标准，还是存在跨文化的底线——精神世界构建的元困境 |
| B-07 | 文明冲突：当不同的精神构造相撞 | 亨廷顿；竞争协同律 | 不同精神构造撞在一起时，边界就是战场 |
| B-08 | 全球化与文化杂交：边界在溶解还是在重新固化 | 全球化理论；开放性原理 | 文化不再封闭，杂交与反弹同时发生 |
| B-09 | 人类命运共同体：一种超大规模的文化新构造 | 开放性原理；超大规模开放系统 | 精神世界的容量能不能装下"全人类"——对"平天下"的系统论回应 |
| B-10 | 结语：客观精神与主观精神如何相互塑造 | 回扣 B-序、文章三/十九 | 你构建文化，文化也构建你；精神世界模型在时间中循环生长 |

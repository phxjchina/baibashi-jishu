# 让计算机替你"走遍所有岔路"——模型检测怎么自动找 bug？

> **上期回顾**：上一期我们建好了一个红绿灯的模型（状态 A、B、C 加上切换规则），相当于画出了"路口怎么变灯"的精确骨架。骨架有了，问题来了：怎么用它证明"车不会撞"？这就要握住形式化方法的第二个手柄——**验证**。而验证里有个特别省心、特别自动化的本事，叫**模型检测**。

## 一、验证的两大门派

**验证（verification）**，就是用数学方法检查"系统真的满足了当初定下的规约"。

干这件事有两条路：

- **演绎证明（theorem proving）**：人带着证明工具，像做数学题一样，一步步把"系统满足性质"推出来；
- **模型检测（model checking）**：把**模型**和要查的**性质**都交给电脑，电脑自己去搜。

今天只讲后者——因为它最"懒人友好"：你不用自己推，电脑替你把所有可能的路走完。

## 二、模型检测，一句话说清

**名-实对应**：模型检测（model checking），就是——把你建好的**模型**，和你要查的**性质**，一起喂给一个算法；算法**把模型里所有能到达的状态都搜一遍**，看性质是不是在每个状态都成立；一旦发现不成立，它还能把"坏事是怎么发生的"那条路径（行话叫**反例**，counterexample）给你揪出来。

对比一下测试：测试是你自己挑几条路试一试；模型检测是电脑把**每一条**可能的路都走完。这正是前两期说的"从靠运气到靠证明"——对有限状态的模型，它能给你一个确定答案：要么"满足"，要么"不满足，并附上反例"。

## 三、拿红绿灯模型，看电脑怎么找 bug

先回顾上期的模型：

- 状态 A：南北向绿、东西向红；
- 状态 B：南北向红、东西向绿；
- 状态 C：全红（切换时的缓冲）；
- 切换顺序：A → C → B → C → A，如此循环。

我们要查的性质（一条"安全性"）：**任何时刻，南北向和东西向都不会同时绿**。

电脑怎么做？它从初始状态出发，把"能到达的所有状态"全列出来——也就是 {A, C, B} 以及它们之间的跳转。然后挨个状态问："这一刻，有没有同时绿？"

- 在 A 里，只有南北绿；
- 在 B 里，只有东西绿；
- 在 C 里，全红。

三个状态全都不冲突。结论：这个模型满足安全性，车不会撞。电脑相当于给你盖了个"通过"的章。

现在换一种情况。假设程序员手滑，把切换逻辑写错了，让 A 和 B 之间能直接跳、或者某个瞬间 A、B 同时出现。电脑一搜，立刻撞见"东西向和南北向同时绿"的状态，马上报警：**性质不满足！** 并且把**反例路径**甩给你：初始 → A →（错误跳转）→ 南北东西同时绿。

注意，它不是只说一句"有 bug"，而是告诉你"bug 是这样一步步发生的"。这一点比测试强太多——测试常常只告诉你"程序挂了"，模型检测告诉你"挂的那条具体路径"，debug 时直接定位到那一步。

## 四、为什么这事了不起（顺带提个图灵奖）

模型检测把"验证"从"少数专家拿纸笔手推"变成了"电脑自动跑"，可重复、能规模化。为此，Clarke、Emerson、Sifakis 三位学者拿到了 2007 年的**图灵奖**——这是计算机界的最高荣誉，分量相当于诺贝尔奖。

今天它已经用在实打实的地方：芯片巨头很早就把模型检测拿来查处理器里的微妙错误，航天、铁路信号系统里也有它的身影。

回看咱们这个专栏的两本底稿：一本讲"怎么把要求写得精确"（规约），一本讲"怎么让电脑自动查模型"（模型检测）——正好拼成"写清楚 + 查清楚"这套流程的两端。

## 五、也别把它神化：状态爆炸

讲透才负责：模型检测不是万能。真实系统里，状态数常常随着部件增多**指数级暴涨**——这叫**状态爆炸**（state-space explosion）。状态多到电脑存不下、搜不完，模型检测就卡住了。

对策（后面会单开一期细讲）：上上期说的"简化"在此立功——抽象掉无关细节，让模型保持小巧；再用更聪明的数据结构去压缩表示（符号化方法）；或者只挑关键路径查。

所以模型检测擅长的是"状态有限、行为清楚"的关键子系统，不是拿去查整个微信那样的巨无霸。

## 六、小结 & 下期预告

这期三句话收住：

1. **模型检测**就是：电脑把你模型里所有可能状态搜一遍，查性质是否成立；
2. 不成立就给**反例**，直接定位 bug；
3. 它让验证自动化、规模化，是形式化方法的"杀手锏"之一，但也有**状态爆炸**这道坎。

下期预告：说了半天"性质"，性质到底怎么写成电脑能懂的话？这就引出**时态逻辑**（temporal logic）——"永远""最终""下一步"这些带"时间"的词，怎么变成公式。下期还用红绿灯，演示怎么把"永远不会同时绿"写成一条带有"永远"含义的时态逻辑公式。

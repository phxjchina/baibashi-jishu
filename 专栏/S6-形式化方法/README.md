# S6 · 形式化方法

形式化方法用严格的数学语言给"软件/系统到底对不对"这件事兜底：先把要的性质写清楚，再让机器自动证明或自动找反例。本专栏分两条线——通俗科普（从"软件为什么会出错"讲起）与正式成稿（Event-B、UPPAAL、抽象精化等实战）。

- **[正式成稿](./正式成稿/)**（3 篇）— 正式成稿：偏学术与工程实战，涉及 Event-B、UPPAAL、时态逻辑、抽象精化。

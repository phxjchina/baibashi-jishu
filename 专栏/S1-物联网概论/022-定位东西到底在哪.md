# 定位：东西到底在哪？——天上那几座灯塔

## 一、我当年的困惑

全景篇最后一站，聊一个天天用、却从没人讲透的本事——**定位**。

共享单车怎么知道车停没停到框里？冷链车怎么知道制冷没断？家长怎么知道娃到没到校？答案全指向同一个技术：**给万物确定"它在哪"。**

我当年的困惑特别具体：手机地图一开，我在哪清清楚楚。可这"清楚"是怎么来的？天上又没有摄像头盯着我。

## 二、原理：几座会报时的灯塔

定位的原理，白话讲，就一个类比：**天上的灯塔。**

GPS、北斗这些卫星，本质是一座座**会报准确时间的灯塔**：它们不停地广播"现在是 X 时 X 分 X 秒"。

你的手机收到信号后，干一件聪明事——**比对时间差**：

- 信号以光速跑，跑得越远，到达越晚；
- 手机收到"卫星 A 的报时"比"卫星 B 的报时"晚了那么一丝丝；
- 这一丝丝的差，就能算出"我到 A 比到 B 远了多少米"。

一颗卫星，划出一个"距离圈"；两颗，两个圈交出一条线；三颗，锁定一个面；**四颗，锁定空间中的一个点**——也就是你的位置。

所以行话说"GPS 定位要四颗星"——不是玄学，就是几何：三颗定平面，第四颗顺带校正你手表（手机自己的钟不准）。

## 三、北斗：咱们自己的灯塔群

提到定位，必须说**北斗**——中国自建的全球卫星导航系统。它跟 GPS 是同行，都是天上的灯塔群，但它有两手绝活：

**绝活一：短报文。**

GPS 是"只能听、不能说"的哑巴灯塔——你只能收它的信号，没法回话。北斗不一样，它允许你**通过卫星发回一百来字的消息**。

这一手要命在哪？想想：地震把基站全震塌了，手机没信号，人在野外失联——这时候，带北斗短报文功能的设备，能通过卫星把"我在某山沟，人受伤"发回指挥中心。**没手机信号的地方，它是最后的生命线。**

**绝活二：亚太更密，精度更稳。**

北斗的卫星布局在亚太地区特别密，在咱家门口，信号质量和精度都有优势。而且它是**自主可控**的——关键基础设施的定位，命脉得攥在自己手里。

从"碗里有两颗北斗星"（90 年代）到全球组网，这条路走了二十多年。这里面有太多"外国人能做到、我们为什么不行"的较劲故事，我上课常讲，讲的是技术，也是那股气。

## 四、定位在物联网里怎么用

定位在物联网里，从来不是"导航"那么简单，它是**给系统装的空间感**：

- **共享单车**：定位 + 电子围栏，不停进框里就持续计费——**位置成了规矩**；
- **冷链物流**：车走到哪、车厢几度，一起上报——**位置成了追溯**；
- **牛羊放牧**：每头牛戴个北斗项圈，草原上跑丢了，手机一查坐标——**位置成了牧鞭**；
- **老人儿童**：电子围栏一画，出了安全区就报警——**位置成了牵挂**。

看出规律没？定位一旦接上平台，就不再是"看我在哪"，而是**触发动作**：越界报警、超区计费、走失预警。它还是挂在那条反馈环上的一环——**环的"空间感知"。**

## 五、一点"为什么这么想"的思考

写到这，全景篇就齐了。咱们把这个系列在脑子里过一遍：

**物**（被感知、被控制的对象）→ **五官**（感知）→ **神经**（网络）→ **普通话**（MQTT）→ **指挥**（EMQ X）→ **记忆**（数据库）→ **脸面**（应用系统）→ **免疫**（安全）→ **空间感**（定位）……

一环一环，全挂在同一条**反馈环**上：**自己看、自己想、自己动手、自己再看效果。**

最后想说点我这两年越来越强的感受。咱们中国人学技术，早年习惯仰头看——灯塔是 GPS 的，系统是别人的，协议是人定的。可现在不一样了：北斗在天上，EMQ X 在 GitHub 上被全世界用，鸿蒙、华为云、国产数据库一茬茬地长出来。

**技术这东西，从来没有天生的"谁的地盘"。** 会白话、肯下笨功夫、敢较真——灯塔谁都可以建。

这大概就是我想把这个系列写下去的原因：把技术讲白，让更多人对"物的崛起"这件事，有份参与的底气。

# 物联网不就是互联网换皮嘛？主语一换，全变了

## 一、我当年的困惑

"物联网不就是互联网换个皮？"——这句话，我在酒桌上、饭局上听过不下十遍。

说的人一脸"我早就看透了"的表情：不就是给原来那些网站、App，多接点传感器数据嘛，新瓶装旧酒。

我还真较真去研究过这个事。研究完的结论是：**皮确实有点像，但瓤完全变了。** 今天讲清楚，变在哪。

## 二、先看互联网是怎么干活的：像打电话

你用微信发消息，整个过程是这样：

1. 你（人）主动发起："我要给他发句话"；
2. 你的手机把请求发给服务器；
3. 服务器转给对方的手机；
4. 完事。你不问，服务器不吭声。

发现没有？这一整套，**主语是你这个人**。服务器是个"应声虫"——你问它才答，你不问它巴不得歇着。行话管这个叫"请求-响应"：**人请求，机器响应。**

所以互联网本质上是**被动**的：它坐在那等人来使唤。

## 三、再看物联网怎么干活：像自动巡航

换个场景。一片几千亩的玉米地，要防霜冻。

以前的土办法：派人蹲在地里看温度计，低了就敲锣放烟。现在怎么做？地里布满温度探头，探头自己每隔几分钟测一次，**不用谁问它**；一发现温度要跌破临界值，它自己就把数据报到云上；云上的程序一算"要出事"，自己就下令开风机、点防霜烟；风机烟点完，探头再测——温度回来了，系统收工。

注意这一串里有三个要命的变化：

1. **没人使唤它**——是设备自己盯着、自己开口（这叫"发布-订阅"，跟"请求-响应"是两码事）；
2. **它自己拿主意、自己动手**——不是等人来看数据；
3. **它干完还回头看效果**——发现没管用，会接着调。

第三点，就是我从现在起要反复念的那条主线——**反馈**。互联网基本没有这条回程线，物联网全指着它活。

## 四、一个"换皮没换魂"的翻车故事

有个团队做"物联网平台"， demo 给我看：网页挺漂亮，设备列表、实时曲线、历史数据一应俱全。我看完问："这跟传统网站的后台，区别在哪？"

负责人想了想，特实诚："多了个设备图标，数据是传感器来的。"

这就是典型的"换了皮，没换魂"。

数据还是只存、只显示、只给人看；人看了，再自己拿主意、自己动手。**整个"反馈环"里最值钱的半截——"自己判断、自己执行、再看效果"——根本没做，还是人在中间当苦力。** 那不叫物联网，那叫"把传感器数据搬到了网页上"。

皮是网页，魂还是老网站。

## 五、那"瓤"到底变成什么了？

主语从"人"换成"物"，牵一发动全身：

|      | 互联网      | 物联网            |
| ---- | -------- | -------------- |
| 谁发起  | 人使唤机器    | 设备自己开口         |
| 机器干啥 | 你问它才答    | 自己盯着、自己判断、自己动手 |
| 干完咋样 | 答完就完了    | 回头看效果，不对再调（反馈） |
| 核心   | 把信息送到人眼前 | 把事替人办了         |

看明白没？**物联网不是"互联网 + 传感器"，它是把原来那套"人使唤机器"的系统，改造成了"机器自己闭环"的系统。** 这不是加个模块的事，这是从头到脚换了套活法。

## 六、一点"为什么这么想"的思考

为什么这么多人爱说"换皮"？因为大家拿眼睛看到的那点东西在判断——都是屏幕、都是数据、都是联网，看着是挺像。

但一个系统的本质，从来不在它"长什么样"，在它**怎么转**。就像两个人，一个是你问他一句他答一句，另一个是你还没开口他已经把事情办好了——长得再像，也是两种人。

**看系统，要看它的"转法"：是等人来使唤，还是自己盯着、自己办、自己看效果。** 这一条，比任何界面都更能说明它是什么。

这也是名-实对应学习法提醒我们的：别拿"长得像"当"是同一个东西"。"物联网"这个名的实，不是"带传感器的网站"，是"一个能自己闭环的自动系统"。

## 下一篇最是关键：《**物联网是三层？别误会，它是一个环。**》——我要把教材上那张三层图，给你重新画一遍。
